# 8. Настройка динамической трансляции адресов на маршрутизаторах HQ-RTR и BR-RTR:

::: details
* Настройте динамическую трансляцию адресов для обоих офисов в
сторону ISP, все устройства в офисах должны иметь доступ к сети
Интернет
:::

Для трансляции адресов (NAT) будем использовать iptables, как и ранее на ISP.

Устанавливаем iptables на обоих маршрутизаторах.

```shell
apt-get install iptables
```

Создаём правило MASQUERADE в таблице `nat`, цепочке `POSTROUTING` для интерфейса в сторону ISP.

```shell
iptables -t nat -A POSTROUTING -o ens18 -j MASQUERADE
```

<!-- потом прописываешь команду, потом сохраняешься всю эту байду с помощью -->

Сохраняем правила iptables в файл.

```shell
iptables-save > /etc/sysconfig/iptables
```

::: warning
Используйте `>` (перезапись), а не `>>` (дозапись). При использовании `>>` правила будут дублироваться при каждом сохранении.
:::

Добавляем демон `iptables` в автозагрузку.

```shell
systemctl enable iptables
```

__Повторите те же действия на обоих маршрутизаторах — HQ-RTR и BR-RTR.__

## 8.1 Проверка работоспособности

После настройки NAT все машины в обоих офисах должны иметь доступ в интернет.

Проверяем доступность репозиториев с любой клиентской машины, например HQ-SRV:

```shell
# HQ-SRV
apt-get update
```

Если список пакетов успешно обновился — NAT работает корректно.
