# 11. Настройте часовой пояс на всех устройствах согласно месту проведения экзамена

::: details
* За исключением виртуального коммутатора, в случае его использования
:::

Устанавливаем часовой пояс на всех машинах в соответствии с местом проведения экзамена.

```shell
timedatectl set-timezone <зона>
```

Список доступных зон можно посмотреть командой:

```shell
timedatectl list-timezones
```

::: tip
Для Екатеринбурга, к примеру, зона будет `Asia/Yekaterinburg`:

```shell
timedatectl set-timezone Asia/Yekaterinburg
```
:::

Проверяем результат:

```shell
timedatectl
```

__Повторите на всех машинах стенда.__
