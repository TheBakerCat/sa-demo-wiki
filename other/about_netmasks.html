INFO

Для получения кол-ва хостов, вмещающихся в подсеть, количество нулевых бит из двоичного вида маски мы берём за n и производим вычисление по следующей формуле: 2n−2

2 вычитается в связи с тем, что:

  • Первый адрес подсети используется в качестве адреса сети
  • Последний адрес подсети используется в качестве broadcast

Исключение из правила составляют маски /31 и /32 (конкретный хост).

Как выбрать маску по условию задания ​

В заданиях ДЭ формулировки обычно звучат так: «сеть должна вмещать не более N адресов» или «не менее N адресов».

Алгоритм прост:

  1. Берём требуемое количество хостов из задания
  2. Прибавляем 2 (адрес сети + broadcast)
  3. Находим ближайшую степень двойки, которая >= полученного числа
  4. Это и есть размер нашей подсети. Префикс = 32 − количество нулевых бит

TIP

Пример из задания 1.1:

Локальная сеть в сторону HQ-CLI (VLAN 200) должна вмещать не менее 16 адресов

16 хостов + 2 = 18 → ближайшая степень двойки = 32 → это /27 (32 адреса, 30 хостов)

Но подождите. Нам нужно не менее 16, а /28 даёт ровно 16 адресов (14 хостов). 14 < 16, значит /28 не подходит. Берём /27.

А вот если бы было «не более 16 адресов»: /28 даёт ровно 16 адресов — подходит.

Структура подсети ​

Для любой подсети структура адресов выглядит так:

АдресНазначение
Первый адрес диапазонаАдрес сети (нельзя назначать хостам)
Второй адрес → предпоследнийИспользуемые адреса хостов
Последний адрес диапазонаBroadcast (нельзя назначать хостам)

INFO

Пример для сети 192.168.200.0/29 (8 адресов):

АдресНазначение
192.168.200.0Адрес сети
192.168.200.1Первый используемый (обычно шлюз)
192.168.200.2 – 192.168.200.6Адреса хостов
192.168.200.7Broadcast

Итого: 6 адресов для хостов из 8 возможных.

Типичные ошибки ​

WARNING

Адрес сети ≠ первый используемый адрес

192.168.100.0/28 — здесь .0 это адрес сети, а не хоста. Первый используемый адрес — .1.

Назначить .0 хосту физически можно, но это приведёт к непредсказуемому поведению сети.

WARNING

«Не более» ≠ «Не менее»

Внимательно читайте формулировку задания. «Не более 32 адресов» означает, что подсеть должна вмещать максимум 32 адреса (берём наименьшую подходящую маску). «Не менее 16 адресов» — подсеть должна вмещать минимум 16 (проверяем, хватает ли нам хостовых адресов).
